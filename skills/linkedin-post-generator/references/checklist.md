# Pre-delivery checklist

Run this against every post before delivering. If any answer is "no" (or "yes" for the don'ts), fix it.

## Voice
- [ ] Is it entirely lowercase?
- [ ] Is it free of corporate words (leverage, unlock, synergy, supercharge, game-changer, "in today's landscape")?
- [ ] Is it free of colorful metaphors? (say it plainly instead)
- [ ] Is it written in first-person "i"?
- [ ] Does it take a clear, contrarian stance — does it argue something, not just inform?
- [ ] Does it punch at a practice/idea, never a person or group?
- [ ] Does it read like the target posts, not the anti-anchor explainer tone?

## Substance
- [ ] Does it prove the point with real mechanics or numbers, not just a clever line?
- [ ] If the point involves a progression/comparison/list, is there a clean breakdown block?

## Structure
- [ ] Do the variants use different hook styles (no repeat back-to-back)?
- [ ] Do the variants vary their close (some takeaway, some question)?
- [ ] Is the length roughly 150–250 words with mobile-friendly whitespace?

## Confidentiality
- [ ] Are all clients generic (no names)?
- [ ] No specific client revenue/financials?
- [ ] Are platform names only used generically, never tied to a specific client?
- [ ] Did I scan for any figure specific enough to identify one client — and flag it above the posts if so?

## Output packaging
- [ ] Does each variant carry its style tag: `[hook: X | body: Y | close: Z]`?
- [ ] Does each variant have a one-line "why this angle" note?
- [ ] If no angle was specified by the user, did I offer 2–3 angle options up top?
